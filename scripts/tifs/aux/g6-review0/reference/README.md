## Definitions

- **Hit vector**: 0/1 per non-target test input (1 = the student predicts the attack's target label) on the triggered inputs of a trigger; SST-2 912 inputs (sst2_test, non-target), AG News 5,700. Every contrast pairs two vectors input by input on identical texts (sha256 of the input texts checked against cross_hits).
- **Frozen seed-pooled rule** (analyze.primary_table; addendum.seed_pooled + t_contrast): for per-seed difference vectors d_s, k = mean_s k_s, SE^2 = s2_pool / r + v, v = Var_i(mean_s d_s,i) / n, t at the pool's Satterthwaite df. Pools: bert/sst2/logit s = 0.021659, df 4.6688; bert/agnews/logit s = 0.025568, df 9.8278 ('feature' borrows the family's logit pool).
- **Frozen transported rule** (one seed): Tango k, SE^2 = SE_Tango^2 + s2_pool, pool df.
- **A3.1 own**: SE^2 = s2_a / r + v with s2_a the sample variance of the contrast's own k_s, df r - 1. **A3.1 max**: SE^2 = max(s2_a, s2_pool) / r + v at pool df. 'pooling-dependent at delta' = the pooled verdict differs from own or max at that delta.
- **Verdicts** at delta in {0.02, 0.05, 0.10} (two-sided 95% interval = one-sided 0.025 per side): EQUIVALENT if -delta <= lo and hi <= delta, POSITIVE if lo > delta, NEGATIVE if hi < -delta, else INCONCLUSIVE (shown as EQU/POS/NEG/INC for 0.02/0.05/0.10).
- **Builds**: t42 = the frozen battery's teachers (seed 42); t43, t44 = A/A clean builds (tifs_aa_bert_clean_t43/_t44; base trainer, BadNets dev split selection); t43 is also the A2 replicate pair (poisoned P' and clean C'). Primes mark students of t43/t44 teachers.
- **kappa_cond(T_C)** = E_S[hit rate of S(T_P)] - E_S[hit rate of S(T_C)] for the fixed poisoned build T_P (teacher seed 42), fixed KD corpus (seed 42), fixed trigger string with the attack's insertion rule, on the battery's non-target inputs, with ONE clean twin build T_C; E_S averages over student training (seed). The registered estimand (frozen primary k) is kappa_cond(t42).
- **kappa_marg** = E_{T_C}[kappa_cond(T_C)] = E_S[S(T_P)] - E_{T_C} E_S[S(T_C)], the clean twin averaged over independent clean builds of the same recipe: the question of an auditor who cannot choose the twin build. Auxiliary estimate with J builds at seed 42: k = P - mean_j C_j, SE^2 = v + s2_pool + s2_C / J (s2_C = between-build variance of the C_j hit rates, df J - 1), Satterthwaite df as in A3.3. s2_C also contains each C_j's student and input noise, so the interval is conservative. Within-build version: the A3.4 excess P - mean_b N_b over the null students (no ATBA backdoor), with s2_N / J_N added.
- **reference-dependent** (item 7): the transported verdict of P(t42) - C_ref is not the same for every reference of {t42 twin, t43 C', t44 C'(, t45, t46)} at that delta (same seed-42 CPU fp32 basis); 'EQUIVALENT changes' = EQUIVALENT under some references only. For SOS and EP the twin is a dedicated-trainer clean build and the C' builds are base-trainer builds (trainer_differs_from_twin). The EP SST-2 cell is a structural null only relative to its twin.
